## rmap0.M_Axi

RMAP memory addresses as seen by an initiator, 32 address bits. rmap0 accepts an access only inside its windows: WIN_CTRL, WIN_BASE and WIN_LAST of window n at 0x100 + 0x10 n of rmap0 (4 windows, Windows_g). After the reset (WinInit_g = WinInitOpen_c) window 0 is open over the whole address space with all permissions and the other windows are disabled, so the whole map is reachable after the reset. Software can narrow the windows. dec0 decodes 19 address bits: the map repeats every 0x00080000 bytes.
